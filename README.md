**Bird** est une application web inspirée de Twitter, développée avec React et JSON Server.  
Elle permet aux utilisateurs de s'inscrire, se connecter, publier des tweets et suivre leur fil d'actualité.

## ✅ Fonctionnalités principales

- 🔐 Inscription et connexion (avec validation)
- 💾 Sauvegarde de session via localStorage
- 📝 Création et affichage de tweets
- 🧵 Fil d'actualité
- 👤 Profil utilisateur
- 🔐 Accès protégé si non connecté
